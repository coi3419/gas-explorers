# 🧪 신나는 기체 탐험대

초등학교 4학년을 위한 반응형 과학 학습 웹사이트입니다. 아이가 만든 **바보 세 마리의 여행** 캐릭터 그림을 활용했습니다.

## 주요 기능

- 홈 / 기체 종류 / 체험 학습 / 퀴즈 도전의 4개 화면
- 산소(O₂), 질소(N₂), 이산화 탄소(CO₂), 헬륨(He), 수증기(H₂O) 학습 카드
- 입자 운동(온도·입자 수), 풍선 부풀리기, 헬륨 풍선 비교 실험
- 10문제 퀴즈와 오답 복습, 별 애니메이션, 최고 점수 기록
- 모바일 및 태블릿 반응형 화면, 학습 진도 브라우저 저장

## 시작하기

웹사이트는 **index.html 단일 파일**로 실행됩니다. 그림과 CSS, JavaScript가 파일에 포함되어 있어 별도의 빌드나 이미지 폴더가 필요하지 않습니다.

## GitHub Pages 공개하기

1. [저장소 Settings → Pages](https://github.com/coi3419/gas-explorers/settings/pages) 열기
2. **Build and deployment → Source**: `Deploy from a branch`
3. **Branch**: `main`, **Folder**: `/(root)` 선택
4. **Save** 클릭
5. 사이트 주소: https://coi3419.github.io/gas-explorers/

> 이 저장소는 공개 저장소입니다. 사용자 제공 캐릭터 이미지도 공개 사이트와 소스에 포함됩니다.
